PROYECTOS PERSONALES

Automatizador de generación de contratos.

Aplicación web para la gestión y generación de contratos automatizados a partir de plantillas.

Se trata del MVP de un proyecto futuro que facilite y agilice la escritura de contratos. Fue realizada durante el verano de 2026 para aprender Spring Boot de manera práctica y asentar los conocimientos aprendidos sobre Java durante el primer curso.

Mini-Contratos permite crear y gestionar personas, plantillas de contratos y bloques de contenido, y generar contratos a partir de una persona y una plantilla seleccionadas. El usuario puede crear personas y plantillas. Las plantillas están compuestas por bloques divididos en dos categorías, 'REUNIDOS' y 'EXPONEN'. Estos bloques pueden ser reorganizados por el usuario. Los bloques pueden incluír una serie de placeholders que acceden a los datos de las personas guardadas en la BD.

Finalmente, el usuario selecciona una plantilla y una persona, y la aplicación crea un contrato con un formato predefinido que incluye el nombre de la plantilla, la fecha seleccionada, la ciudad introducida y sustituye los placeholders por los datos de la persona seleccionada.

CRUD de Gestión de Clientes.

Aplicación de escritorio desarrollada en C# WinForms con acceso a SQL Server.

El proyecto implementa un sistema CRUD completo (creación, lectura, actualización y eliminación de registros) basado en una arquitectura de acceso a datos mediante procedimientos almacenados en SQL Server.

Este proyecto surge durante mis prácticas de 1º de DAW como iniciativa personal. Me basé en la forma de trabajar de la empresa donde realicé las prácticas para entender mejor cómo funciona su ERP y para conseguir aplicar esos conceptos en una aplicación de gestión propia.

Un proyecto muy interesante, puesto que me permitió integrar los conocimientos de diferentes asignaturas del ciclo en un único proyecto por primera vez, utilizando técnicas similares a las usadas en un entorno profesional real.
